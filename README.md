# AJ-entic® — Arif Jawad portfolio

Next.js (App Router) + TypeScript + Tailwind v4 + Motion + Lenis. Dark and reading (sepia) themes.

- `npm run dev` / `npm run build`
- Content lives in `lib/data.ts` (dummy content, replace freely)
- Contact form posts to `/api/contact`; set `RESEND_API_KEY` (and optional `CONTACT_FROM`) in Vercel to send email
- Previous static site is kept in `legacy/`
